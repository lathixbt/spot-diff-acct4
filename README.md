A spot-the-difference game set on a snowy mountain night: six hand-drawn
Canvas scenes — a cabin porch, a frozen lake, a pine forest path, an aurora
ridge, a woodpile shed and a moonlit summit — with 50 fair differences to
find across them. Two near-identical panels side by side, gold rings on every
find, a big "N to find" counter, timer, strikes, hints, a magnifier, keyboard
play, score and streak, WebAudio chimes and a best-night record.

Play it: serve `game/` with any static server (`node serve.ts`, then open
http://localhost:8080) — it runs offline in a desktop browser, no network.

Hand it in: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts` writes
`/output` with `game/`, `screenshots/` and `dossier.json`.
